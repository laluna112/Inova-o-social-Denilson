# AGENTS.md

## Project Context

This repository contains a React frontend for managing school menus.

Start with `README.md` for local setup, environment variables, and publish workflow.

## Key Files

- `src/`: frontend application source.
- `src/api/client.js`: local client for auth and entity operations.
- `vite.config.js`: Vite config.
- `src/lib/AuthContext.jsx`: authentication provider.

## Working Notes

- Use `npm run dev` to start the development server.
- Prefer local data and session storage for development.
- Run `npm run lint` and `npm run typecheck` before finalizing changes.
